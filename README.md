# Грант CRM — CRM для онлайн-школы подготовки к ЕНТ

Демо-прототип CRM, заточенной под школу подготовки к ЕНТ в Казахстане. Это не очередная универсальная воронка: CRM знает про пробные ЕНТ, профильные предметы, проходные баллы на грант, Kaspi-рассрочку и семьи, которые говорят на казахском и на русском.

**Живое демо:** https://sukrievmusa-hash.github.io/crm1/

Работает в браузере без сервера и установки. Демо-данные (90 учеников, ~110 заявок, 9 групп, 4 пробных ЕНТ) генерируются при первом открытии и хранятся в localStorage. Сбросить их можно в «Настройках».

## Что умеет

| Раздел | Зачем школе |
|---|---|
| **Дашборд** | Выручка и её темп, заявки, конверсия, долги, средний балл. Свой вид для каждой роли: директор, менеджер продаж, куратор. |
| **Умные подсказки** | Выводы из данных с кнопкой действия. Например: «заявки, обработанные за 10 минут, оплачивают в N раз чаще», «у 12 учеников до гранта не хватает до 15 баллов — допродайте интенсив», «группа заполнена на 90% — открывайте поток». |
| **Заявки** | Канбан от «Новая» до «Оплачено» с перетаскиванием. Норматив ответа 15 минут: нарушение подсвечивается красным. Автораспределение по менеджерам, «следующий шаг» для каждой заявки, причины отказов. |
| **Оформление оплаты** | Одна кнопка: выбрать тариф, группу и схему (помесячно или Kaspi-рассрочка). Ученик создаётся автоматически, куратор получает задачу «приветственный звонок». |
| **Ученики** | Посещаемость, ДЗ, последний пробный, **прогноз балла к ЕНТ**, **шанс на грант** по выбранной специальности, **риск ухода**, статус оплаты. |
| **Карточка ученика** | График пробных ЕНТ с линией гранта и прогнозом, разбор по предметам, рекомендация, **отчёт родителю в один клик** на языке семьи. |
| **Пробные ЕНТ** | Распределение баллов, самый слабый раздел, топ-10, прирост по группам, импорт результатов из Excel или Google Таблиц (вставкой). |
| **Оплаты** | Просрочки, ожидаемые платежи, доля Kaspi, напоминание родителю, отметка «оплачено». |
| **Рассылки** | Сегменты (должники, новые заявки, риск ухода, результаты пробника), шаблоны на русском и казахском. Язык подбирается под каждую семью. |
| **Публичная форма** | `#/form` — форма «Бесплатный пробный ЕНТ» для сайта. Заявка мгновенно появляется в CRM, открытой в соседней вкладке. |
| **Прочее** | Глобальный поиск (Ctrl+K), задачи с дедлайнами, тёмная тема, меню на казахском, экспорт в CSV, адаптив под телефон. |

## Как показать за 5 минут

1. Откройте демо под ролью **Директор**: дашборд и умные подсказки.
2. **Заявки** → красная карточка без ответа → «Написать» (шаблон на казахском) → «Оформить оплату». Ученик создан, куратору ушла задача.
3. Откройте **форму с сайта** в соседней вкладке и отправьте заявку. Она сразу появится в канбане.
4. **Ученики** → любой ученик: прогноз, шанс на грант, «Отчёт родителю».
5. Переключите роль на **Куратора**, потом на **Менеджера**: у каждого свой экран.

## Что будет в рабочей версии

- Облачная база (например, Supabase/PostgreSQL) с доступами по ролям вместо localStorage.
- Kaspi Pay: счета и автоматическая отметка оплаты.
- WhatsApp Business API и Telegram-бот: отправка сообщений и переписка в карточке.
- Заявки из Instagram и TikTok Lead Ads, вебхук формы сайта.
- Импорт пробных ЕНТ из платформы тестирования школы.

Проходные баллы на грант в демо условные, школа задаёт свои в настройках. Названия и данные вымышлены.

## Структура

```
index.html        каркас приложения
css/app.css       стили (светлая и тёмная тема, адаптив)
js/core.js        утилиты, хранилище, расчёты (прогноз, шанс, риск), UI, роутер
js/seed.js        справочники и генератор демо-данных
js/charts.js      графики на HTML/SVG без библиотек
js/dashboard.js   дашборды и умные подсказки
js/leads.js       заявки, канбан, оформление оплаты
js/students.js    ученики, карточка, отчёт родителю
js/ops.js         группы, оплаты, пробные ЕНТ, задачи
js/comms.js       рассылки, настройки, публичная форма
archive/          первый черновой прототип
```

Локально: `python3 -m http.server` в папке проекта, затем http://localhost:8000 (или просто откройте `index.html`).
